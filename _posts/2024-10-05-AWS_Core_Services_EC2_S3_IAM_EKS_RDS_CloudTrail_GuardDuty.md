클라우드를 처음 접할 때 꼭 알아야 할 AWS 핵심 서비스들! 한눈에 정리해볼게요.

## 1. EC2 (Elastic Compute Cloud)

- 🖥️ **가상 서버 제공**: 원하는 만큼 서버를 생성하고 애플리케이션을 유연하게 운영할 수 있어요.
- 🔄 **자동 확장**: 트래픽에 따라 서버 수를 자동으로 늘리거나 줄일 수 있어, 비용 효율적!
- 💡 **사용 예시**: 웹사이트 호스팅, 백엔드 시스템, 데이터 처리 등 다양한 용도로 사용 가능.

## 2. S3 (Simple Storage Service)

- 📦 **클라우드 스토리지**: 파일을 안전하게 저장하고 언제 어디서든 쉽게 접근 가능!
- 🔒 **강력한 보안**: 99.999999999% 내구성을 보장해 데이터 손실 위험 없이 사용 가능.
- 💰 **저렴한 비용**: 필요한 만큼만 저장소를 사용하고 비용 절감까지 가능해요.

## 3. IAM (Identity and Access Management)

- 🔑 **접근 권한 관리**: AWS 리소스에 대한 접근을 세밀하게 제어할 수 있어 보안 강화.
- 💼 **역할 기반 액세스**: 사용자, 그룹, 역할별로 세분화된 권한 설정이 가능해요.
- 🔐 **보안 강화**: 특정 작업만 허용할 수 있어, 민감한 데이터 보호에 적합합니다.

## 4. EKS (Elastic Kubernetes Service)

- 🐳 **Kubernetes 관리형 서비스**: AWS에서 손쉽게 Kubernetes 클러스터를 운영할 수 있어요.
- 🚀 **자동 확장**: 클러스터의 리소스를 자동으로 관리하고 확장성을 보장합니다.
- 💡 **사용 예시**: 컨테이너 기반의 애플리케이션을 대규모로 배포하고 운영할 때 유리해요.

## 5. LB (Load Balancer)

- ⚖️ **트래픽 분산**: 여러 서버에 트래픽을 분산시켜 애플리케이션의 성능을 최적화할 수 있어요.
- 🌐 **다양한 유형**: Application, Network 등 다양한 로드 밸런서 옵션으로 맞춤형 설정 가능.
- 💼 **사용 예시**: 트래픽이 많은 웹사이트나 애플리케이션의 가용성을 높이는 데 필수!

## 6. RDS (Relational Database Service)

- 💾 **관리형 데이터베이스**: MySQL, PostgreSQL, Oracle 등 관계형 데이터베이스를 쉽게 설정하고 운영할 수 있어요.
- 🔄 **자동 관리**: 백업, 복구, 소프트웨어 패치 등을 자동으로 관리해 줍니다.
- 💡 **사용 예시**: 온라인 쇼핑몰, 블로그 등 데이터 중심의 애플리케이션에 적합해요.

## 7. CloudTrail

- 👀 **사용자 활동 추적**: AWS 계정에서 발생하는 모든 API 호출을 기록해 모니터링을 강화.
- 📝 **로그 저장**: 누가 어떤 작업을 했는지 추적 가능해, 보안 및 컴플라이언스 준수에 유리.
- 🔍 **사용 예시**: 보안 감사 및 이상 활동 탐지, 문제 해결 시 활용할 수 있어요.

## 8. GuardDuty

- 🛡️ **지능형 위협 탐지**: AWS 계정과 인프라에서 발생하는 보안 위협을 자동으로 탐지합니다.
- 🔍 **지속적인 모니터링**: 네트워크 및 계정 활동을 모니터링하여 비정상적인 행동을 실시간으로 감지.
- 💡 **사용 예시**: 잠재적인 공격 시도나 데이터 유출을 빠르게 탐지해 대응할 수 있어요.

## 9. Lambda

- ⚡ **서버리스 컴퓨팅**: 서버를 관리할 필요 없이 코드를 실행할 수 있어요.
- ⏳ **이벤트 기반**: 특정 이벤트가 발생할 때만 실행되므로 비용 절감에 탁월합니다.
- 💡 **사용 예시**: 파일 업로드 시 자동으로 이미지 리사이징, 실시간 데이터 처리 등 자동화 작업에 적합.

---

**💡 요약:**

- **EC2**: 확장 가능한 가상 서버.
- **S3**: 안전하고 저렴한 클라우드 스토리지.
- **IAM**: 세밀한 접근 권한 관리.
- **EKS**: Kubernetes 관리형 서비스.
- **LB**: 트래픽을 분산시켜 서버 부담 줄이기.
- **RDS**: 자동 관리형 데이터베이스.
- **CloudTrail**: 모든 활동을 기록해 보안 관리 강화.
- **GuardDuty**: AWS 인프라의 실시간 위협 탐지.
- **Lambda**: 서버리스 컴퓨팅으로 이벤트 기반 자동화.
