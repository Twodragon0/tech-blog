{% comment %} 이전/다음 포스트 네비게이션 `page.previous` / `page.next` walk raw `site.posts`, so they happily point at a post whose URL vercel.json 301s elsewhere (`superseded_by` — the 30 April 2026 dailies consolidated into 4 weekly rollups). This nav renders on EVERY post, so it is the most-seen surface of that defect: measured 2026-09-10 on a local build, 5 reader-reachable pages carried a prev/next into a 301, the 4 rollups among them — a reader paging out of a rollup landed back on a redirect. The default pair is kept for the common case (no extra work on 660 of 665 pages). Only when a default neighbour is superseded do we build the filtered, date-ascending list and step over the whole superseded run at once — they are contiguous through April, so a one-step walk would not be enough. A superseded post itself is absent from `nav_posts`, so `nav_idx` stays -1 and it renders no nav. That is correct: it is no longer part of the reading sequence, and on Vercel nobody reaches it anyway. {% endcomment %} {% assign nav_prev = page.previous %} {% assign nav_next = page.next %} {% if nav_prev.superseded_by or nav_next.superseded_by or page.superseded_by %} {% assign nav_posts = site.posts | where_exp: "p", "p.superseded_by == nil" | sort: "date" %} {% assign nav_idx = -1 %} {% for p in nav_posts %} {% if p.url == page.url %}{% assign nav_idx = forloop.index0 %}{% break %}{% endif %} {% endfor %} {% assign nav_prev = nil %} {% assign nav_next = nil %} {% if nav_idx >= 0 %} {% if nav_idx > 0 %} {% assign nav_prev_i = nav_idx | minus: 1 %} {% assign nav_prev = nav_posts[nav_prev_i] %} {% endif %} {% assign nav_next_i = nav_idx | plus: 1 %} {% assign nav_last = nav_posts.size | minus: 1 %} {% if nav_next_i <= nav_last %} {% assign nav_next = nav_posts[nav_next_i] %} {% endif %} {% endif %} {% endif %} {% if nav_prev or nav_next %}
