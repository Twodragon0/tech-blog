# 게시물 원문 예제

10줄을 넘는 본문 코드를 읽기 쉬운 별도 파일로 분리한 보관본입니다.

- 원문을 그대로 보존했으며 최신 API 호환성이나 보안 적합성을 새로 검증한 배포 코드가 아닙니다.
- 특히 MDM 권한, 복구키, 자동 병합, 보안 알림 처리 예제는 운영 환경에 그대로 실행하지 마세요.
- JSON 주석을 포함할 수 있어 JSON 예제는 `.jsonc`로 보관합니다.
- GitHub `blob/main` 참조는 이 파일들을 저장소에 반영한 뒤 유효합니다. 게시 전에 글과 예제 파일을 함께 반영해야 합니다.
- Mermaid는 독자가 구조를 바로 볼 수 있도록 본문에 유지합니다.
