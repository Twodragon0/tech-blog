# 2026-11-05 테크 블로그 우선순위 개선

## 범위와 선정 기준

로컬 저장소의 초안 포함 빌드, 게시물 검사, Python 테스트를 기준으로 사용자에게 보이는 오류, 검증 실패, 초안 게시 준비 순서로 처리했다. 기존 미추적 WebP 파일은 변경하지 않았다. 운영 서비스 설정과 배포는 변경하지 않았다.

## 반영

1. Falco 글의 Go 템플릿 Timestamp가 Liquid로 해석되어 값이 손상되는 문제를 raw 태그로 수정했다. 초안 포함 Jekyll 빌드에서 경고가 사라지고 출력에 Timestamp가 남는 것을 확인했다.
2. 만료된 core-bare-watch 진단 훅 검토일 때문에 전체 테스트가 실패했다. 현재 core.bare=false이고 전이 로그는 확인되지 않았다. 원인이 규명되지 않아 훅은 유지하고 검토일을 2026-11-19로 제한 연장했다. 이는 원인 해결이 아니며 해당 날짜에 로그를 다시 검토해야 한다.
3. Mac mini 초안에 1200x630 OG SVG와 image_alt를 연결하고 검사기가 deprecated로 분류하는 category 단일 필드를 제거했다. categories 배열은 유지했다. SVG는 저장소가 별도 취급하는 -og.svg 명명 규칙을 사용했다.

## 후속 우선순위

- P1: 11월 19일까지 core.bare 전이 로그를 검토하고 진단 훅의 유지 또는 종료를 결정한다. 기한을 근거 없이 반복 연장하지 않는다.
- P2: check_posts.py가 보고한 기존 4개 게시물의 긴 코드 블록 5개를 외부 참조와 별도 예제로 정리한다. 검사는 335개 게시물을 대상으로 실행됐다.
- P2: Mac mini 초안의 실제 PR URL, 전력 측정, 재부팅 복구 증거를 확보한 뒤 게시한다. 문서가 설계를 운영 실증으로 오인시키지 않도록 유지한다.
- P3: Python 테스트가 알린 폰트 tier-1 외 한글 7자를 검토한다. 현재는 tier-2로 렌더링되며 글자 누락으로 확인된 것은 아니다.

- 초안 포함 Jekyll 빌드 성공, Liquid 경고 없음.
- 초안 frontmatter 및 SVG XML 검사 성공.
- 변경된 Python 파일 Ruff 및 Mypy 성공.
- 훅과 SVG 크기 검사 관련 테스트 18개 성공.
