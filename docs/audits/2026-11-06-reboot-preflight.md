# 2026-11-06 재부팅 복구 시험 사전 점검

판정: **시험 준비 미완료, 실제 재부팅 보류**. 재부팅은 수행하지 않았다.

| 확인 | 관측 결과 | 판정 |
|---|---|---|
| 디스크 여유 | 약 30GiB | 확보됨 |
| 전원 설정 | sleep=0, womp=1, autorestart=1 | 설정 확인 |
| FileVault | On | 설정 확인 |
| supportsauthrestart | true | 지원 확인, 실행 성공 아님 |
| Paseo | launchd PID와 응답 존재, 루트 HTTP 404 | 프로세스 도달 가능, 인증 health 미검증 |
| 웹훅 | 로컬 /health HTTP 200 | 로컬 health 확인 |
| queue/watchdog | launchd 등록, 최근 종료 코드 0 | 작업 복구 성공은 미검증 |
| 서비스 유형 | Paseo는 gui/501 LaunchAgent | 로그인 전 기동 보장 없음 |
| 현장 복구 담당자·화면·키보드 | 확인되지 않음 | 필수 미충족 |
| 승인된 복구키 접근·외부 접속 장치 | 확인되지 않음 | 필수 미충족 |
| 진행 중 작업 drain·큐 백업 | 실행하지 않음 | 시험 직전 필요 |

실행 전 [시험 계획](../runbooks/macmini-headless-reboot-recovery.md)의 사전 준비를 충족해야 한다. 설정 지원과 웹훅 200만으로 재부팅 가능 판정을 내리지 않는다. 사용자 LaunchAgent의 복구 요구를 충족하는지 실제 로그인 경계 시험으로 확인하고, 필요 시 서비스 구조 변경은 별도 검토한다. 비밀이나 계정 설정을 변경하지 않았다.

추가 관측: `last reboot`와 `kern.boottime`은 2026-11-05 22:10(KST) 부팅을 가리켰고, 11월 6일 00:50 기준 uptime은 약 2시간 40분이었다. 현재 서비스가 이 부팅 이후 실행 중인 것은 확인되지만, 부팅 방식·현장 로그인 유무·복구 소요 시간·인증 재시작 실행 주체는 확인되지 않았다. 따라서 무인 복구 시험의 통과 증거로 채택하지 않는다.
