# midword 42셀을 재요약할 것인가 — 측정에 근거한 판정

**결론: 재요약하지 말고, 셀 자체를 단어 경계로 되감아라.** 중위 2자 제거로
42/42가 게이트를 통과하고, 네트워크도 새 텍스트 생성도 필요 없다.

> **실행 완료 (2026-09-07).** 안 D를 42셀 / 35포스트에 적용했다. 제거 문자수
> min 2 / 중위 2 / 최대 16. `digest_midword_baseline.txt` 는 **0 엔트리**,
> `BASELINE_MAX = 0` — midword 게이트는 이제 예외 없는 순수 차단 게이트다.
> `regen_quality_baseline` 은 변동 없었다(0 added / 0 removed): 되감기가 어떤
> 포스트의 점수 구간도 넘기지 않았다.

대상: `scripts/digest_midword_baseline.txt` 의 42개 셀 / **35개 발행 포스트**.
(원래 44였고, 카테고리 집계 행 2건은 다른 결함이어서 이미 복구됐다 — 아래 §4.)

## 1. 먼저 반증된 전제

베이스라인 헤더는 *"원문이 사라져서 단어를 완성하려면 지어내야 한다"* 고 적고
있었다. **틀렸다.** 42개 원문(`news.hada.io`) 전부 살아 있고, 잘린 조각을
그대로 포함한다 — 즉 이어쓰기는 창작이 아니다.

측정 함정 2개를 함께 남긴다.

- **HTTP 200 이 기사를 뜻하지 않는다.** 1차 프로브에서 8건이 "조각 없음"이었고
  8건 모두 본문 260자 `브라우저 확인 | GeekNews` 였다.
- **변수는 링크 사멸이 아니라 User-Agent 였다.** 실제 Safari UA 로는 8/8 기사
  반환 + 8/8 조각 포함. 첫 수치(34/42)는 프로브 결함이다.

## 2. 네 가지 안과 실측 비용

| 안 | 무엇을 | 실측 결과 | 판정 |
|---|---|---|---|
| **A** 방치 | 아무것도 안 함 | 35개 발행 포스트에 중간에서 끊긴 셀 42개 잔존. 게이트는 계속 그랜드파더 | 기각 — 비용 0이지만 이득도 0 |
| **B** 원문에서 이어붙이기 | 조각 뒤를 다음 종결부까지 붙임 | 42/42 이어붙이기 가능하나 **중위 +268자, 최대 +8402자** | **기각** (§3) |
| **C** 고친 파이프라인으로 재요약 | 원문 재수집 → `_korean_brief_summary` 재실행 | 42셀 / 35포스트 재작성 + 재수집 + 게이트 전면 재검증 | 보류 — 이득 대비 과중 |

## 3. B를 기각하는 근거

한국어 요약 불릿은 종결부호를 쓰지 않고 `~음`/`~함` 으로 끝난다. 그래서
"다음 마침표까지"라는 기계적 규칙이 **다음 항목으로 넘어간다.** 실측 예:

```
+8402자  '문자 추가로 이어지지 않은 제안은 거절로 간주되며, 목록은 100% …'
+   9자  '아 있음 태양보다'
```

현재 셀은 90~170자다. 중위 +268자를 붙이면 셀이 2~3배가 되어 파이프라인
자체 셀 캡에 걸리고, 결국 **같은 단어 경계 로직으로 다시 잘라야 한다.**
즉 B는 D를 경유하지 않고는 완결되지 않는다.

## 4. 왜 44가 아니라 42인가

집계 행 2건(`2026-04-18:401`, `2026-07-31:418`)은 RSS 사전절단이 아니라
`_extract_trend_keyword()` 한국어 분기의 `segment[:40]` 하드 슬라이스였다 —
바로 아래 영어 분기는 `rsplit(" ", 1)[0]` 로 되감는데 한국어 분기만 빠져
있었다. 별개의 **살아 있던** 절단 지점이고, 꼬리 `워`/`방` 은 게이트가 막으므로
잠재 발행 차단이었다. 수정 + 복구 완료(`test_trend_keyword_word_boundary.py`).

## 5. D 실행 결과 (실측)

- 42셀 / 35 발행 포스트 수정. 제거 문자수 min 2 / 중위 2 / 최대 16.
- `regen_quality_baseline` **변동 없음** (0 added / 0 removed). 산문 점수가
  구간을 넘지 않았다 — 사전에 갱신이 필요할 것으로 봤으나 불필요했다.
- 게이트 11종 exit 0: `digest_quality_report --all`(mid-word 0, grandfathered 0)
  · `regen_quality_baseline --check` · 체크리스트 H2 · 템플릿 에코 ·
  보일러플레이트 · 깨진 링크 · 카드 제목 언어 · KST · `check_posts` ·
  미번역 · ruff. pytest 5295 passed / 5 skipped.
- `digest_midword_baseline.txt` **0 엔트리**, `BASELINE_MAX = 0`.
- 변환 재현: 각 셀에 `_drop_dangling_lone_syllable` + `_trim_dangling_particles`
  를 고정점까지 반복. 베이스라인 tail 로 **끝나는** 셀이 정확히 1개일 때만
  수정하고 그 외에는 ABORT — 다른 위치의 부분 문자열 일치를 잘못 고치지 않도록.

## 6. 범위 밖이지만 붙어 있는 문제 (별건)

40자 이하 제목 10건이 `초`·`팀`·`풀`·`전`·`건`·`킷` 으로 끝나 게이트에
걸린다. 이들은 **절단이 아니라 제목의 자연스러운 끝**이며(`2026년 초`,
`7개 주요 Bitcoin 채굴 풀`), 절단 경로를 타지 않는다. allow-list 를 넓히는
문제이고, deny-by-default 게이트를 약화시키는 판단이므로 여기서 다루지 않는다.
